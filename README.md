**1. Color System (Palette + Rationale)**
Palette:
Primary Blue (#0055FF) — used for main buttons, links, highlights.
Rationale: Strong, trustworthy, techy blue that gives clarity and focus on CTAs.

Dark Navy (#0B0F23 / near black) — background for header/footer and text.
Rationale: Deep dark color for professionalism and contrast, easy on eyes.
Soft White (#F9FAFB) — backgrounds and content areas.
Rationale: Keeps the site light, clean, and readable.
Accent Orange (#FF8C00) — subtle highlights and icons.
Rationale: Adds warmth and energy to balance the cool blue, grabs attention.
Gray Shades (#777, #CCC) — for secondary text, borders, and subtle UI elements.
Rationale: Neutral grays add hierarchy and visual calm.

2. **Breakpoint Logi**
   layout uses a mobile-first responsive approach with roughly these breakpoints:
XS (<640px):
Single-column layout everywhere for ease of scrolling on small devices.
SM (≥640px):
Simple stacking but introduces minor padding and spacing adjustments.
MD (≥768px):
Switches to a 2-column grid for sections like services, testimonials, and resources.
Navigation menu switches to horizontal from hamburger.
LG (≥1024px):
Expands grid to 3 or 4 columns in some content areas (like partners or resources).
Adds more whitespace for readability and balance.
XL (≥1280px):
Maximum width container centers content with wider gutters.
Some font sizes and padding increase for more comfortable reading on large screens.

3. **Creative Divergences from Typical Mockup (beyond colors)**
**Use of Photography and Texture:**
incorporating strong real photos for the “about” and “resources” sections, adding authenticity and emotional connection that a flat mockup might lack.
**Dynamic Carousel for Testimonials:**
Instead of static quotes, a slider creates movement and user engagement.
**Layered UI Elements:**
For example, some images slightly overlap text blocks or have subtle shadows — this adds depth and sophistication.
Consistent Iconography Style:
   **use of clean vector icons that align visually across components, unifying the look**.
**Whitespace and Padding Choices:**
spacing feels balanced, breathing room helps focus attention and avoid clutter.
Footer with Social Links + Newsletter Signup:
A full functional footer rather than a minimal one, helping with user retention and outreach.
